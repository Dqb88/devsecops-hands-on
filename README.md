# DevSecOps Hands-On

Build Your First Secure Pipeline

## Technologies
- Linux
- Git and GitHub
- Python and FastAPI
- Docker
- Terraform
- Ansible
- GitHub Actions
- Security Scanning

## Quick Start

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt

## Run Application

python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

## Run Tests

python -m pytest -v
